## 📖 О сайте

### 🎯 Для кого сделан сайт

Сайт создан специально для **новобранцев Учебной роты (УР)** и **курсантов Военной академии (ВА)** — военнослужащих, впервые поступивших на службу или переведённых из других госструктур.

### 🚀 Для чего сделан сайт

Портал решает ключевые задачи адаптации новобранцев:

1. **🤖 Умный помощник** — чат-бот отвечает на 100+ частых вопросов 24/7, снижая нагрузку на командиров
2. **📚 Структурированная база знаний** — от вводного инструктажа до критериев повышения
3. **✅ Интерактивные чек-листы** — отслеживание прогресса по повышению с сохранением в браузере
4. **🎓 Простая навигация** — понятная структура без перегруза информацией
5. **📋 Готовые шаблоны** — копирование докладов и текста присяги в один клик
6. **🔍 Глобальный поиск** — мгновенный доступ к любой информации на сайте

## 🧰 Ключевой функционал

### 🤖 Чат-бот помощник

Интеллектуальный помощник на чистом JavaScript, доступный с любой страницы сайта.

**Возможности:**

- 📊 **100+ вопросов** в базе знаний по 10 категориям
- 🎯 **Умный алгоритм поиска** с весами для длинных фраз
- ⚡ **Быстрые кнопки** для самых частых вопросов
- 🔗 **Ссылки на страницы** в ответах
- ⌨️ **Индикатор набора** (typing animation)

**Категории вопросов:**

- 💬 Общие термины (статик, todo, бодикамера)
- 🚨 Коды реагирования (КОД-1 — КОД-4)
- 📏 Дисциплина и субординация
- 👔 Дресс-код и внешний вид
- 🗺 Зоны и ограничения
- 📚 Обучение и лекции
- 📈 Повышение и звания
- 🛡 Посты и поставки
- 💻 Discord и командование

**🔧 Логирование неизвестных вопросов:**

Если бот не знает ответа, вопрос автоматически отправляется в Discord через Webhook в приватный канал разработчика для последующего добавления в базу.

### ✅ Интерактивные чек-листы (promotion.html)

- 🔀 **Переключатель УР / ВА** — отдельные чек-листы для каждого подразделения
- 📊 **Прогресс-бары** с плавной анимацией
- 💾 **Автосохранение** в localStorage (прогресс не теряется)
- 🏷 **Цветные бейджи** подразделений (УБ, МР, ССО, УБ/УВП/ВКГ)
- 🌟 **Золотая рамка** для эксклюзивного повышения ВА (Мл. сержант → Сержант)

### 🔍 Глобальный поиск

- 🔎 Поиск по **13 страницам** сайта
- ⚖️ Учёт релевантности (заголовок > keywords > описание)
- ✨ **Подсветка совпадений** в результатах
- ⌨️ **Навигация клавиатурой**: `↑` `↓` `Enter` `Esc`
- ⚡ **Горячая клавиша** `Ctrl + K` (или `Cmd + K` на Mac)
- ⏱ **Debounce** 300ms для плавной работы

### 📖 Словарь с фильтрами (dictionary.html)

- 🔤 **40+ терминов** по 4 категориям
- 🏷 **Цветные бейджи**: 🏛 Подразделение, 📖 Термин, 🎖 Звание, 📻 Команда
- 🔍 **Поиск в реальном времени** с подсветкой совпадений
- 📊 **Счётчик результатов**

### 📋 Копирование в один клик

- 📝 **Шаблоны докладов** для каждого поста
- 🇷🇺 **Текст присяги** с кнопкой копирования
- ✅ **Визуальная обратная связь** — кнопка становится зелёной с ✅

### 🔊 Озвучка текста (oath.html)

- 🗣 **Web Speech API** — озвучка текста присяги русским голосом
- ⏹ **Управление** — остановка повторным кликом
- 🌐 Работает в Chrome, Edge, Safari
  (бесполезно, но забавно)

## 💻 Технологии

Сайт написан на **чистом фронтенде** без фреймворков, сборщиков и бэкенда:

- **HTML5** — семантическая разметка, accessibility (ARIA-атрибуты)
- **CSS3** — CSS-переменные, Grid, Flexbox, transitions, animations
- **Vanilla JavaScript** — без зависимостей, ~800 строк оптимизированного кода
- **localStorage** — сохранение прогресса чек-листов и настроек
- **Web Speech API** — синтез речи для озвучки присяги
- **Clipboard API** — современное копирование с fallback для старых браузеров
- **Discord Webhook** — логирование неизвестных вопросов боту

### Дизайн

- 🌑 **Тёмная тема** (синий + золото) — визуально отличается от основного сайта УБ
- 📱 **Полная адаптивность** — ПК, планшет, мобильный
- 🍔 **Бургер-меню** с динамическим позиционированием (не перекрывает поиск)
- 🔤 **Шрифты**: **Oswald** (заголовки) + **Inter** (текст)
- 🎨 **Плавные анимации** — hover-эффекты, пульсация, transitions
